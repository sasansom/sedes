This is a subset of CLTK source code,
containing only files related to Greek lemmatization,
for local use by SEDES
without bringing in all of CLTK as a dependency.

It comes from https://github.com/cltk/cltk
at tag v1.1.7
(commit 8240db9117bc2d8d16eaca1b59d2e90d47fee426).
It has subsequently been modified to remove components
not needed by SEDES and to work as a local module.

See LICENSE for the upstream license
and README.rst for the original README.
